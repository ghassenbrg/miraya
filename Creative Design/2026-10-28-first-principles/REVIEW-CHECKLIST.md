# Miraya design review checklist

> **NOT APPROVED UNTIL EXPLICITLY APPROVED.**

- [ ] Reflection Seam is distinctive and readable at 16 / 32 / 64 px.
- [ ] macOS and Android/Google TV icons feel like one family.
- [ ] Future iOS direction is acceptable as a reserved extension.
- [ ] Mac source → seam → destination hierarchy is clearer than the previous sidebar/settings composition.
- [ ] Discovery, empty/offline, manual address, pairing and permission recovery are understandable.
- [ ] Start / Pause / Resume / Stop hierarchy is correct.
- [ ] Quality presets read as maximums with automatic adaptation.
- [ ] Audio never implies microphone capture.
- [ ] Saved trust can be removed individually.
- [ ] TV pairing digits and D-pad focus read across a room.
- [ ] Back/Stop behavior is visible and predictable.
- [ ] Fit / Fill / Stretch and symmetric 0–10% edge-margin semantics are clear.
- [ ] App viewport, physical output mode and encode ceiling are clearly different.
- [ ] 4K panel does not imply 4K screen-sharing encoding.
- [ ] Netflix handoff wording makes no DRM/browser-session/account-transfer claim.
- [ ] Approve identity / Mac / TV / full direction, or request another exploration.
